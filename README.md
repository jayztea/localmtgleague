# Local Magic League 

A web application for tracking Magic: The Gathering Commander games with your local "commander leage", player statistics, and league rankings. 

## Technology Stack

Frontend:
- React
- TypeScript

Backend:
- Node.js
- Express

Database:
- MySQL
